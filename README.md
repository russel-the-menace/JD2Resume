# JD2Resume

JD2Resume brings a job description and a candidate's resume into one focused workspace. It helps turn scattered experience, education, and job requirements into a clearer resume tailored to the role, while keeping the candidate in control. The left side organizes each section for editing, and the live preview on the right makes it easy to refine the story, layout, and professional skills before the final version is ready.

University data is sourced from the domestic university datasets in [China-World-University-Index](https://github.com/theo-the-menace/China-World-University-Index/tree/main/output).
